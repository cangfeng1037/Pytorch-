## 原神月绽放伤害公式 (Genshin Impact Moonbloom Damage Formula)

```
月绽放伤害 = (基础区乘 + 额外提升) * 抗性区 * 双爆区 * 擢升区
```

### 公式参数说明 (Formula Parameters):
- **基础区乘**: Base Multiplier
- **额外提升**: Additional Boost
- **抗性区**: Resistance Zone
- **双爆区**: Crit Zone (Critical Rate × Critical Damage)
- **擢升区**: Elevation Zone
